# Report font

`NotoSansKR-VF.ttf` is bundled for browser-generated PDF reports so Korean
and Vietnamese text can be embedded and rendered consistently.

- Family: Noto Sans CJK KR (variable TTF)
- Upstream: https://github.com/notofonts/noto-cjk
- Download guide: https://github.com/notofonts/noto-cjk/tree/main/Sans
- License source: https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE
- License: SIL Open Font License 1.1 (see `OFL.txt`)

The file in this repository is an unmodified redistributable font asset.
